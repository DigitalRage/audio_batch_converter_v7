Why this version is different

This build is a true static site. GitHub Pages can host it directly, and the browser performs the conversion locally. The first conversion downloads the FFmpeg WebAssembly core from jsDelivr and then caches it in the browser. The single-thread core is intentional so the page does not depend on special cross-origin-isolation headers. xHE-AAC is shown as unavailable because the standard FFmpeg browser core does not include the exhale encoder.
